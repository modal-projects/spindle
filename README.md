# Router benchmark evidence for Spindle PR #88

Saved plots from the routing experiments. These are historical experimental runs, not a new benchmark of the cleaned integration. Earlier candidates and controls remain here for completeness; their labels identify the policy/run.

The final three-arm comparison uses separate executions with matched engine configuration but different cloud/region placement. Latency quantiles include completed requests only. The last 30 minutes include rollout drain; do not interpret that interval as saturated throughput.

Labels: KV-aware = custom sticky; approximately KV-aware = Modal sessions; Our router (LoRA + KV-aware) = memory-aware candidate.
